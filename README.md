# Dana Nails 💅✨

Agenda de citas de Dana Nails: las clientas eligen servicio, día y hora, y Dana confirma desde su panel.

- `index.html`: la app (funciona en el teléfono y se puede agregar a la pantalla de inicio).
- `firestore.rules`: reglas de seguridad de Firebase (copiar en Firestore → Reglas).
